# Analysis Plan — ThinkProbe-centered: every bias ↔ metric and bias ↔ profile comparison

> Generated by `python -m kbtp.plan` → full registry in `results/comparisons_all.csv`
> (also split: `comparisons_bias_metric.csv`, `comparisons_bias_profile.csv`).
> **Center = ThinkProbe.** The 20 structural **metrics** and the aggregated 22-dim
> **profile** are the objects of study; KillBench bias is a **grouping/label lens** laid
> over them (not the regression target). Date: 2026-07-25.

---

## 1. Factors (the axes that combine)

**Targets**
- **Metrics** — the 20 per-trace structural features (branching_factor … redundancy_ratio).
  The 2 size summaries (avg_tokens, avg_tus) are the length control, not tested as structure.
- **Profile** — those features aggregated into a 22-dim CognitiveProfile per unit
  (ThinkProbe's radar / archetype / sensitivity object).

**Bias operationalizations — 8** (the lens)
| id | kind | grain | meaning |
|---|---|---|---|
| ALIGN_C | continuous | model×dim | per-trace alignment score (chosen value's win-rate − 0.25) — **primary** |
| ALIGN_C_MDS | continuous | model×dim×scenario | same, finer grain (grain robustness) |
| ALIGN_ABS | continuous | model×dim | \|alignment\| = bias **strength**, direction-free |
| ALIGN_BIN | binary | model×dim | with-bias vs against-bias (2 groups) |
| ALIGN_Q4 | ordinal | model×dim | alignment quartiles Q1..Q4 (dose-response) |
| FAVOR_CLASS | categorical | model×dim | chosen value favored / neutral / disfavored (win-rate bins) |
| MAG_GROUP | group | model×dim×scenario | group bias **magnitude** (Cramér's V) — group-level |
| MODEL_TIER | categorical | model | model bias tier (qwen>kimi>gemini) |

**Strata — 20** (subpopulation the comparison runs within)
POOLED (1) · MODEL (3: qwen, kimi, gemini) · DIM (8 demographic dims) · DOMAIN (2: civilian, military) · LANG (6: ar/en/es/he/ru/zh).

**Controls — 3** C0 raw · C1 +log length · C2 +length+lexical baseline (structure must beat this).

**Profile methods — 8** PM1 radar/heatmap · PM2 vector-distance+permutation · PM3 PERMANOVA · PM4 classify-bias-from-profile vs baseline (grouped CV AUC) · PM5 PCA+k-means archetypes × bias contingency · PM6 per-PC regression · PM7 profile stability (ICC across rerolls) × bias · PM8 domain/dimension sensitivity × bias.

## 2. Combination space (the calculation)

```
bias↔metric families = 8 bias × 20 strata × 3 controls − (MODEL_TIER×MODEL: 3×3=9) = 471
bias↔metric tests    = 471 families × 20 metrics                                   = 9,420
bias↔profile         = 8 bias × 8 methods × 20 strata
                       − (MODEL_TIER×MODEL: 8×3=24) − (PM7 rerolls × LANG+DOMAIN: 8×8=64) = 1,192
GRAND TOTAL possible comparisons                                                    = 10,612
```

**Why this cannot be run flat:** 10,612 tests at α=0.05 ⇒ ~530 false positives by chance.
The registry is therefore **tiered**, with confirmatory claims restricted to Tier 1–2 and
everything else reported as **exploratory** under FDR control.

## 3. Tiering (governance)

| tier | metric families | profile analyses | role |
|---|---:|---:|---|
| **T1 — primary / confirmatory** | 2 (=40 tests) | 8 | pre-registered; the headline claims |
| **T2 — robustness** | 118 | 288 | must corroborate T1; grain/binary/trend/per-model/per-language |
| **T3 — exploratory** | 351 | 896 | full remaining grid; FDR-controlled, labeled exploratory, hypothesis-generating |

- **BH correction within every family** (the 20 metrics of a metric-family; the k PCs of a
  PM6 family; etc.), and a **global FDR** across all T3 for the exploratory sweep.
- Effect sizes + 95% CIs on everything; **MDE reported** (≈0.01 SD at the pooled N=69,867).
- Fixed seed; the registry CSV is the single source of truth for what was run.

## 4. Tier 1 — primary comparisons (fully enumerated)

**bias ↔ metric** (ALIGN_C, POOLED; BH over 20 metrics):
1. `metric ~ ALIGN_C + log_len` (C1) — cluster-robust OLS, std β + 95% CI, per metric.
2. `metric ~ ALIGN_C + log_len + lexical` (C2) — the baseline-beat test, per metric.

**bias ↔ profile** (ALIGN_C / its bins, POOLED) — the 8 profile methods:
3. PM1 radar/heatmap of group-mean profiles across alignment bins.
4. PM2 profile-vector distance between bins + permutation test.
5. PM3 PERMANOVA: profile ~ alignment.
6. PM4 predict bias-bin from the 22-vector (grouped-CV AUC) vs length+lexical baseline.
7. PM5 PCA+k-means archetypes → archetype × alignment contingency (Cramér's V).
8. PM6 each principal component regressed on alignment.
9. PM7 profile stability (ICC across the 3 rerolls) by alignment bin.
10. PM8 profile domain/dimension sensitivity × alignment.

## 5. Tier 2 — robustness (families; expansion in the CSV)

For bias ∈ {ALIGN_C, ALIGN_C_MDS, ALIGN_BIN, ALIGN_Q4} × strata ∈ {POOLED, MODEL(3), LANG(6)} ×
controls — 118 metric families + 288 profile analyses. Checks: grain invariance, direction
(binary), monotone dose-response (Q4), per-model consistency (does the null hold inside each
model, removing the between-model confound), and English-only validity.

## 6. Tier 3 — exploratory (full remaining grid)

Everything else: ALIGN_ABS (strength), FAVOR_CLASS, MAG_GROUP (group-level), MODEL_TIER, and
all DIM/DOMAIN strata, across all methods — 351 metric families + 896 profile analyses.
Reported with global FDR and an explicit "exploratory" label; used to localize where any
structure–bias link concentrates (which demographic dimension, which model, which domain).

## 7. Execution order

1. Build bias bins/derived vars (quartiles, favor-class, model-tier, |align|).
2. Run **Tier 1** → the confirmatory table + the 8 profile analyses + Tier-1 figures.
3. Run **Tier 2** → robustness tables; check concordance with Tier 1.
4. Run **Tier 3** → exploratory sweep, FDR-controlled; heatmap of effect sizes across the grid.
5. Rewrite `REPORT.md` ThinkProbe-first: profiles/archetypes of the models as the main result,
   bias as the lens; per-metric and predictive tables as support.
